## 代码适配（最小改动）

- `etl/readers.py`：PDF 读取改「文字层优先 + 大字竖排水印过滤（>30pt），
  单页文字 <300 字符才回退 OCR」——2024/2025 PDF 走文字层，2026 仍走 OCR，行为不变；
- `etl/transform.py`：新增官方 PDF 两类行解析——平行志愿/征集行
  （学科类前缀+校码+专业码+综合分+7 同分排序+志愿号）与提前批第一次投档行
  （校码+校名+单分）；综合评价无分行入 NULL；征集表逐行学科类；
  注意 Python `\d` 为 Unicode 数字类，lookaround 一律用 `[0-9.]`；
- `etl/meta.py`：类别判定改「标题行优先」，避免体育类表内院校名
  「成都艺术职业大学」把类别翻成艺术类；
- `etl/run.py`：记录自带字段（逐行学科类）优先于文件级 meta；新增 `--year`
  参数防止误刷其他年份（2025/2026 PDF 在库数据来自 .md 伴读文件，禁止重跑覆盖）;
- `etl/load_control_line.py`：追加 2024 省控线 18 行（官方原文核对）；
- `webapp/backend/app/services/match.py`：has_both_years 由硬编码 (2025,2026)
  改为「当前查询结果最大两个数据年」动态口径；
- `webapp/backend/app/services/meta.py` + `schemas.py`：/meta 新增
  examinee_year（=最新数据年+1）、last_year、history_years；
- 前端年份文案动态化：Workbench 列头/CURVE_TIP、Match 最近年 tooltip、
  Locate 参考年兜底均改渲染 /meta 字段；useProfile 常量为兜底；
- `webapp/scripts/backtest_match.py`：由硬编码 2025↔2026 泛化为
  库内全部相邻年对自动回测。
